# إدارة محل الخياطة — Tailor Shop Manager

تطبيق أندرويد احترافي لإدارة محلات الخياطة الرجالية: متابعة **الخياطين** و**القصاصين** و**العاملين**، تسجيل الأجور والمسحوبات والمصروفات، وإصدار **تقارير وفواتير PDF** احترافية بشعار المحل.

واجهة عربية كاملة (RTL) • Material Design 3 • وضع فاتح وداكن • يعمل بالكامل **بدون إنترنت**.

## المميزات

### لوحة التحكم
عرض مباشر لعدد الخياطين والقصاصين والعاملين، إجمالي الأجور والمسحوبات والمصروفات، صافي المستحقات، آخر العمليات المضافة، ورسوم بيانية سريعة.

### الخياطون
- إضافة خياط (الاسم، رقم الجوال اختياري، الملاحظات، أجرة الثوب الافتراضية)
- تسجيل عدد الأثواب المنجزة مع التاريخ واليوم
- احتساب الإجمالي تلقائياً (العدد × أجرة الثوب)
- المسحوبات، المصروفات الشخصية، المصروفات العائلية
- مجاميع أسفل الصفحة: إجمالي أجور الخياطة، المسحوبات، المصروفات الشخصية والعائلية، **صافي المستحق**

### القصاصون
- إضافة قصاص (الاسم، الجوال، الملاحظات)
- عدد القصات وأجرة القصة مع الاحتساب التلقائي
- المسحوبات والملاحظات
- مجاميع أسفل الصفحة: إجمالي الأجور، إجمالي المسحوبات، **المتبقي**

### العاملون
- إضافة عامل (الاسم، الوظيفة، الجوال، الراتب الشهري)
- خيار «هل لديه نسبة؟» مع تحديد النسبة المئوية
- احتساب النسبة تلقائياً من الإنتاج (بضغطة واحدة داخل نموذج الإضافة)
- الرواتب المصروفة، المكافآت، المسحوبات، المصروفات الشخصية والعائلية
- مجاميع أسفل الصفحة: الراتب، مجموع النسبة، مجموع المسحوبات، **صافي المستحق**

### المصروفات
تصنيفات جاهزة: إيجار، كهرباء، ماء، أدوات، قماش، خيوط، صيانة، نقل، أخرى — مع التاريخ والمبلغ والوصف والملاحظات، ورسم بياني دائري للتوزيع.

### البحث والفلاتر
بحث سريع في كل الأقسام بالاسم أو التاريخ أو المبلغ أو رقم الجوال. فلترة حسب اليوم/الأسبوع/الشهر/السنة/فترة مخصصة، أو حسب موظف معين.

### التقارير
تقرير خياط • تقرير قصاص • تقرير عامل • تقرير المصروفات • تقرير الأرباح • يومي • أسبوعي • شهري • سنوي — مع اختيار فترة زمنية (من – إلى).

**التصدير:** PDF احترافي، Excel، مشاركة مباشرة، وطباعة.

### تخصيص التقارير والفواتير
من الإعدادات يمكن رفع **شعار المحل** من الهاتف مع معاينة قبل الحفظ، وتغييره أو حذفه في أي وقت، وضبط **موضعه** (يمين/وسط/يسار) و**حجمه**. كما يمكن إدخال اسم المحل ورقم الجوال والعنوان، ورفع **ختم المحل أو توقيع المدير**، وكتابة رسالة تذييل قابلة للتعديل.

بعد الحفظ تُستخدم هذه البيانات تلقائياً في كل التقارير والفواتير. يظهر في كل مستند: الشعار، اسم المحل، بيانات التواصل، عنوان التقرير، التاريخ، الفترة الزمنية، رقم التقرير، الجداول، المجاميع، رقم الصفحة، والتذييل.

### النسخ الاحتياطي
إنشاء واستعادة نسخة احتياطية، تصدير واستيراد قاعدة البيانات، اختيار مكان الحفظ، ومشاركة النسخ — كل ذلك بضغطة واحدة.

### حماية البيانات
تفعيل/تعطيل/تغيير كلمة مرور PIN مكوّنة من **4 أو 6 أرقام** (مُخزّنة بتجزئة SHA-256)، مع زر 👁 لإظهار وإخفاء كلمة المرور. الأقسام المحمية: المصروفات، التقارير، الأرباح، الأجور، النسخ الاحتياطي، وإعدادات التطبيق.

### الإحصائيات
رسوم بيانية للمصروفات والأجور والأرباح، أكثر الموظفين إنتاجاً، عدد العمليات اليومية، ومقارنة شهرية وسنوية.

### الإشعارات
تذكير بصرف الرواتب، تذكير بالنسخ الاحتياطي، وتنبيه عند تجاوز المصروفات الحد المحدد.

### ميزات إضافية
تعديل وحذف كل البيانات مع رسالة تأكيد • **سجل نشاط** لكل العمليات • حفظ تلقائي • **أرقام مرجعية تلقائية** لكل عملية (`WRK-00001`، `TXN-00001`، `EXP-00001`) • ملاحظات غير محدودة • تثبيت الموظفين المفضلين • **أرشفة حسب السنوات** • **تصفير شهر معين** مع نسخة احتياطية تلقائية قبل التصفير • دعم الطباعة • أداء عالٍ مع آلاف السجلات عبر فهارس SQLite.

## بنية المشروع

```
lib/
├── main.dart                  # نقطة الدخول، السمات، RTL
├── core/
│   ├── constants/app_info.dart
│   ├── db/app_database.dart   # مخطط SQLite + الفهارس + الأرقام المرجعية
│   ├── theme/app_theme.dart   # Material 3 فاتح/داكن
│   └── utils/                 # التنسيق العربي والفترات الزمنية
├── models/                    # Person, WorkEntry, MoneyTxn, Expense, ShopProfile...
├── repositories/              # طبقة الوصول لقاعدة البيانات
├── providers/                 # إدارة الحالة (Provider)
├── services/                  # PDF, Excel, النسخ الاحتياطي, الحماية, الإشعارات
├── widgets/                   # عناصر مشتركة ورسوم بيانية
└── screens/                   # كل الشاشات
```

### قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `persons` | جدول موحّد للخياطين والقصاصين والعاملين (عمود `type`) |
| `work_entries` | عمليات العمل: العدد × سعر الوحدة = الإجمالي |
| `money_txns` | المسحوبات، المصروفات الشخصية/العائلية، النسب، الرواتب، المكافآت |
| `expenses` | مصروفات المحل العامة |
| `app_settings` | إعدادات مفتاح/قيمة |
| `activity_logs` | سجل النشاط |
| `counters` | عدّادات الأرقام المرجعية |

التواريخ مخزّنة كأعداد صحيحة (milliseconds epoch)، وكلمة المرور بتجزئة SHA-256.

## البناء

### عبر GitHub Actions (لا يحتاج Android Studio)

ادفع الكود إلى GitHub وسيبدأ البناء تلقائياً. حمّل ملف APK من تبويب **Actions ← آخر تشغيل ← Artifacts**.

يمكن أيضاً تشغيله يدوياً من **Actions ← بناء APK ← Run workflow**.

لإصدار رسمي مع Release:

```bash
git tag v1.0.0
git push origin v1.0.0
```

> مجلد `android/` غير مرفوع في المستودع عمداً؛ ينشئه الـ CI عبر `flutter create .` ثم يعدّله سكربت `tool/patch_android.py` (اسم التطبيق بالعربية، الأذونات، وتفعيل desugaring المطلوب للإشعارات). هذا يضمن توافق المشروع مع أي إصدار Flutter مستقبلي دون تعارضات Gradle.

### محلياً

```bash
flutter create . --platforms=android --org com.hsnpmt --project-name tailor_shop_manager
python3 tool/patch_android.py
flutter pub get
flutter run                    # للتجربة
flutter build apk --release    # للإصدار
```

**المتطلبات:** Flutter 3.29+ • Dart 3.3+ • JDK 17

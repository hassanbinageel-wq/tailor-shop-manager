# أدوات المشروع

- `patch_android.py` — يُشغَّل بعد `flutter create .` لضبط اسم التطبيق العربي، أذونات
  أندرويد، وتفعيل core library desugaring المطلوب لحزمة الإشعارات.
- `verify_structure.py` — مدقق ثابت سريع: يفحص توازن الأقواس، ويتأكد من أن كل
  الاستيرادات المحلية موجودة، وأن كل رمز مستخدم مستورد فعلاً. يُشغَّل من جذر المشروع:
  `python3 tool/verify_structure.py`
